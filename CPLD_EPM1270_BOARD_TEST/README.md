# EPM1270 板卡测试专用工程

打开 board_test.qpf。器件 EPM1270T144C5，时钟 30 MHz。本工程独立于原 top.qpf。引脚沿用 ../CPLD_EPM1270_STATCOM_MODBUS 的板卡映射。光纤 RX PIN42 物理空闲低，顶层反相后运行 Modbus RTU 地址 1、115200 bit/s、8N1。上位机通过光纤串口适配器使用同一条通信链路；板卡没有另设 PC UART 引脚。
配套上位机源码已归档至专用上位机仓库 [host_app](https://github.com/rongsen123/host_app) 下的 `CPLD_BOARD_TEST_HOST_V0106/` 目录。

## 功能

- ADS7818 电压原始 12 位采样。为适配 EPM1270，寄存器 0003 当前回报最新样本，与 0002 相同，不做 256 点平均。GUI 显示 0～4095 的原始 ADC 码，不直接表示伏特。
- 温度频率输入按 100 ms 窗口计数。5000 脉冲阈值和频率越高温度越高的方向沿用参考工程，需按实际传感器标定。
- 旁路反馈、对端故障、备用开入、硬件过压、两路驱动故障均可读。
- 风机和旁路继电器为低有效。上电及 STOP 状态关断；仅在 START、链路在线且没有未屏蔽故障时接受测试控制位。
- 两组桥臂输出相同的互补测试 PWM，不插入死区。pwm_hold_o 高有效；上电、STOP、故障、链路失效时封锁。硬件过压和驱动故障始终直接封锁 PWM 和继电器。
- 故障模拟和屏蔽只允许在 STOP 时配置。硬件过压、驱动故障三位不允许屏蔽。故障原始值与屏蔽后的有效值均可读。

上板前确认功率级与驱动电源已隔离，核对 PIN140～144 的实际电气作用、低有效继电器极性和温度传感器曲线。本工程完成逻辑与 Quartus 编译验证，尚未完成真实板卡波形和功率实验验证。

## Modbus 寄存器

所有 16 位数据高字节先传，CRC16/Modbus 低字节先传。请求固定 8 字节。FC04 支持一次读取 0000～000F 内最多 16 个寄存器；FC03 一次读取一个保持寄存器；FC06 单寄存器写入。异常响应为 01/02/03。

| FC04 地址 | 内容 |
| --- | --- |
| 0000 | 本次互补 PWM 固件版本 0106（用于核对实际烧录镜像） |
| 0001 | 有效请求计数，低 8 位循环 |
| 0002 / 0003 | 最新 ADS7818 原始码 |
| 0004 | 温度脉冲计数/100 ms |
| 0005 | bit0 链路、bit1 ADC 有效、bit2 温度有效、bit3 有效故障 |
| 0006 / 0007 | 原始故障高/低字；高字为 0 |
| 0008 | START/STOP 回显 |
| 0009 | 有效请求计数 |
| 000A～000D | 总错误、UART、CRC、不完整帧计数；低 8 位循环 |
| 000E | 开入/输出状态，位定义见下文 |
| 000F | bit12 PWM 有效，bit11:0 屏蔽后的有效故障 |

000E 位：0 旁路反馈，1 对端故障，2 备用开入，3 硬件过压，4/5 驱动故障 1/2，6 超温，7 温度传感器故障，8 ADC 曾更新，9 温度曾更新，10 光纤链路在线，11 有效故障，12 RUN，13 PWM 有效，14 风机继电器吸合，15 旁路继电器吸合。

故障位：0 旁路，1 对端，2 上行预留，3 下行超时，4 硬件过压，5/6 驱动故障 1/2，7 软件过压，8 超温，9 预留，10 接收帧错误，11 温度传感器故障。真实故障会锁存；模拟位本身不锁存。

| FC03/FC06 地址 | 内容 |
| --- | --- |
| 0100 | 0 STOP，1 START；有有效故障时 START 返回异常 03 |
| 0101 | STOP 时写 A55A，清除已经消失的锁存故障 |
| 0102 | STOP 时写 C33C，回复完成后软复位内部逻辑 |
| 1000 | 软件过压 ADC 阈值，1～3410，默认 3410；STOP 可写 |
| 1100 | 故障屏蔽位，只允许 0x0D8F 位集合；上电和软复位默认 0x0003（旁路、对端）；STOP 可写 |
| 1101 | 故障模拟位，bit9 保留；STOP 可写 |
| 1102 | bit0 风机，bit1 旁路，bit2 PWM；上电和软复位默认 0x0004；STOP 可写 |
| 1103 | PWM 周期时钟数，600～60000，默认 1500，即 20 kHz |
| 1104 | PWM 分界时钟数，1～周期减 1，默认 750 |

PWM 四路：桥 1A 与桥 2A 同相，桥 1B 与桥 2B 同相；每组 A/B 在 PWM 允许时严格互补、无死区；HOLD 时 A/B 均为低。周期和分界数只能在 STOP 时改。软件过压阈值采用连续 3 个 ADC 样本越限确认。寄存器实时读取，跨多个响应字节时不保证整帧快照一致。

## 上位机操作

board_test_cli.py 使用 pyserial。例如：

    python board_test_cli.py COM5 status
    python board_test_cli.py COM5 write 0x1101 0x0002
    python board_test_cli.py COM5 read 0x000E --input
    python board_test_cli.py COM5 write 0x1101 0x0000
    python board_test_cli.py COM5 write 0x1102 0x0004
    python board_test_cli.py COM5 start
    python board_test_cli.py COM5 stop
    python board_test_cli.py COM5 clear

start 会驱动实际板卡输出，先确认接线和功率级隔离。1102=4 只申请 PWM；1102=1/2/3 申请风机、旁路或两者。故障模拟后先写 1101=0；真实锁存故障需在来源消失后 STOP 并执行 clear。

## Windows 图形上位机

直接双击 dist/SST_BoardTest_Console_v5.exe。选择光纤适配器 COM 口并连接，即可每 100 ms 读取采样、开入、原始故障和有效故障；STOP 状态可设置故障屏蔽、故障模拟、开出控制、PWM 周期与分界数。START 按钮直接写入运行命令。需要重新打包时运行 build_exe.bat（本机已安装 PyInstaller 与 pyserial）。旧版 host_app 使用 CRC8 帧协议，与本测试工程的 Modbus RTU 协议不兼容。


故障明细区会把十六进制故障字解码为故障名称，并区分有效故障、已屏蔽故障、当前输入和历史锁存。GUI 轮询周期为 100 ms，低于 CPLD 的 500 ms 下行超时；旧版 1 秒轮询可能导致下行超时 bit3 锁存。

界面每 2 秒读回一次 1100/1101 保持寄存器，以中文名称显示当前屏蔽配置与故障模拟配置；即使没有实际故障，已配置的屏蔽位也会列出。

RUN=1 不代表 PWM 已使能：必须在 STOP 状态将 1102 写为 0x0004（bit2），然后 START；确认 PWM=1 后在 PIN141～144 观察输出，PIN140 的 HOLD 应为低。

## 当前发布版本（0x0106）

- 烧录文件：`releases/board_test_pwm_pair_check_v0106.pof`。
- Windows 上位机：`dist/SST_BoardTest_Console_v5.exe`；也可运行 `build_exe.bat` 从源码重新打包。
- 默认故障屏蔽 `0x0003`（旁路反馈、对端故障），默认开出控制 `0x0004`（仅 PWM）。START 按钮直接启动。
- PIN144 与 PIN143 互补，PIN142 与 PIN141 互补，无故意插入的死区。只有 GUI 显示 `PWM=1` 时才应看到互补波形；封锁时四路均低。
- FC04 地址 0000 应读到 `0x0106`，用于核对板上正在运行的镜像。如果版本正确而物理管脚仍同相，需要检查探头接点、共地和板上接线。
- GUI 的电压 ADC 值是 ADS7818 最新 12 位原始码（0～4095），没有换算成伏特；FC04 地址 0002 与 0003 当前相同。
