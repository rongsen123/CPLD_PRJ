# DSP与CPLD Modbus RTU接口

链路参数：115200 bit/s、8N1、Modbus RTU；CPLD从站地址`1`。CRC16初值
`FFFF`、多项式`A001`、低字节先发送。16位寄存器数据高字节先发送。

## FC04输入寄存器

| 地址 | 内容 |
|---|---|
| `0000` | 协议版本`0103` |
| `0001` | 有效请求计数/心跳 |
| `0002` | ADS7818原始12位ADC码 |
| `0003` | 256点分块平均ADC码 |
| `0004` | 温度脉冲计数/100 ms |
| `0005` | bit0链路在线、bit1 ADC有效、bit2温度有效、bit3总故障、bit4保留 |
| `0006` | 32位故障高字，当前为0 |
| `0007` | 32位故障低字，使用母版12位故障映射 |
| `0008` | START/STOP命令回显 |
| `0009` | 有效Modbus请求计数 |
| `000A` | UART/CRC/不完整帧综合错误计数 |
| `000B` | UART停止位错误计数 |
| `000C` | Modbus CRC错误计数 |
| `000D` | t3.5到期的不完整请求帧计数 |

DSP周期读取`0000-000D`共14个寄存器。正常回复固定33字节，开头为
`01 04 1C`，末尾为CRC低字节、CRC高字节。

## FC03/FC06保持寄存器

| 地址 | 访问 | 内容 |
|---|---|---|
| `0100` | FC03/FC06 | `0=STOP`、`1=START`，只记录回显 |
| `0101` | FC06 | STOP状态写`A55A`，清除已消失的锁存故障 |
| `0102` | FC06 | STOP状态写`C33C`；先完整回显8字节请求，再软复位内部通信、ADC、温度监测和故障锁存逻辑 |

命令：

- START：`01 06 01 00 00 01 49 F6`
- STOP：`01 06 01 00 00 00 88 36`
- 清故障：`01 06 01 01 A5 5A 22 9D`
- 软复位：`01 06 01 02 C3 3C 79 17`

FC06成功时原样回显8字节请求。非法功能返回异常01，非法地址返回02，
非法数值或START状态清故障返回03。
